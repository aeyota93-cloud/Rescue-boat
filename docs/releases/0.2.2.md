# Шлюпка спасения 0.2.2

Windows x64, ядро 4.1.0-rb.18.

- Исправлена обработка отказа ядра: подключение ждёт завершения операции, запуск и остановка выполняются последовательно.
- Правила туннелирования сохраняются с резервной копией. При ошибке изменения отменяются, а приложение показывает причину; повреждённые правила восстанавливаются из копии.
- Исправлен учёт параллельных соединений и их трафика.
- Убрана отдельная подложка статуса подключения в боковой панели.
- Выпускается только установщик. Перед сборкой автоматически выполняются анализ кода и все тесты; повторные сборки веток и изменений документации убраны.

Установите RescueBoat-Setup-x64.exe поверх установленной версии. Её подписки и настройки сохраняются. Данные старой портативной копии автоматически не переносятся.

Для этих исправлений обновлять подписку не требуется. Для смены портов Hysteria2 из версии 0.2.1 обновите подписку в Шлюпке один раз, если этого ещё не делали.

Проверено: 375 автоматических тестов, строгий анализ изменённых файлов и снимки интерфейса. Живое подключение установленной 0.2.2 на компьютере пользователя следует проверить после обновления.

# Шлюпка спасения 0.2.3-test1 (проверочная)

Windows x64, ядро 4.1.0-rb.19.

- Reality (VLESS, XHTTP, порт 8443) теперь работает и с новыми версиями Xray на сервере (26.9.8 и новее): ядро отправляет постквантовый ключ X25519MLKEM768, без которого такие серверы не пускают. Со старыми серверами всё работает как раньше.

Это проверочная версия: автообновление её не предлагает. Установите RescueBoat-Setup-x64.exe поверх установленной.

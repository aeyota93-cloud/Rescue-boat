# Исправления после аудита

По поручению пользователя; релиз не публикуется, версия приложения и appcast не меняются.

- Портативная Windows-сборка и выбор её папок/настроек удалены. Новые сборки выпускают только установщик. Старые опубликованные архивы не изменяются; установленная версия использует прежнюю папку данных. Данные старых portable-копий автоматически в установленную версию не переносятся.
- Отказ применить настройки передаётся вызывающему коду и запрещает запуск/перезапуск ядра. Снимок настроек обновляется только после подтверждения.
- Запуск, остановка и перезапуск выполняются по очереди; повторное нажатие не создаёт обратную операцию. Ошибка не блокирует последующие операции. Неудачная остановка запрещает продолжать удаление активной подписки.
- Состояние правил записывается атомарно, с последней рабочей резервной копией. После сбоя записи UI не считает изменение применённым; экспорт восстанавливается, а при невозможности полного восстановления выводится отдельное предупреждение.
- Повреждённое состояние восстанавливается из копии. Если копии нет, рабочий экспорт сохраняется и изменения блокируются до восстановления или явного сброса списков.
- Ошибка правил видна уведомлением и постоянной строкой на странице туннелирования; окно добавления остаётся открытым при неудачной записи.
- Параллельные соединения сохраняются по ID ядра; счётчики и трафик не теряются до построения UI.
- GitHub Actions запускает анализ и тесты перед компиляцией. Подготовка Flutter и генерация выполняются один раз в задании. Ветки и PR только проверяются; установщик собирается для тега или по ручному запросу. Публикация получает уже проверенный артефакт и запускается только для тега. Изменения только appcast и документации не запускают проверку ветки.
- Fastforge закреплён на 0.6.12; flutter_test объявлен явно.
- Пять отдельных декоративных проверок объединены/убраны; проверки реальных экранов, взаимодействия, клавиатуры и доступности сохранены. Добавлены девять проверок отказов и управления.

Локально: 375 тестов прошли за 27 секунд. Изменённые Dart-файлы проверены строгим анализатором; весь проект проходит команду CI с нефатальными предупреждениями старого кода. YAML workflow разобран библиотекой yaml и проверены порядок тестов, условие сборки и зависимость публикации от успешного задания. Сообщение об ошибке правил проверено на снимках при ширине 1440 и 420 пикселей.

Сборка реального установщика выполняется только в GitHub Actions по отдельному запросу; точное ускорение после удаления portable ещё не измерено.

Проверка рабочей ветки в [GitHub Actions](https://github.com/aeyota93-cloud/Rescue-boat/actions/runs/38536124337) прошла успешно на коммите 993ef60e: 6 минут 57 секунд. Анализ — 36 секунд, тестовый шаг — 1 минута 56 секунд на новом runner. Все шаги упаковки, загрузки установщика и публикации пропущены. Время этого прогона относится к проверке кода, а не к сборке установщика.

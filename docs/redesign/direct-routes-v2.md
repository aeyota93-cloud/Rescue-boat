# «Мимо Шлюпки», вторая версия: замечания после 0.2.6-test5 (27.11.2026)

Первая версия: вкладка «Мимо Шлюпки» (model/direct_routes.dart, widget/tunnel_direct_view.dart).
Windows ведёт маршрут по адресу, а не по программе: адрес из списка идёт мимо Шлюпки у всех программ.
Отсюда общее правило для всех новых точек входа: добавлять можно только то, что уже идёт напрямую
(«Мимо VPN» или «Авто» с прямым путём). Иначе пункт серый: «Сначала выберите «Мимо VPN»».

Уже сделано: имена серверов в подписке (N, F, РФ → N, РФ → F, РФ → туннель → N, РФ → туннель → F).

## Этап 1. Общий диалог и модель

- Один диалог для всех точек входа: «Добавить» (действует с подключения VPN) и
  «Добавить и применить сейчас» (только при включённом VPN, с текущим предупреждением о разрыве).
- Записи хранят, откуда взялись: приложение, сайт (`discord.gg`) или «добавлено вами».
- Не больше 64 адресов за одно добавление: каждый адрес даёт Windows около 30 маршрутов.
- Только публичные IPv4; IPv6 и домашние адреса пропускаются молча, в числе (n) не считаются.

## Этап 2. Точки входа

- Меню пути приложения и группы («Сейчас в сети», «Все правила»): под чертой действие
  «Мимо Шлюпки: N адресов сейчас». Берёт UDP-адреса текущих соединений (без TCP и UDP 443:
  это сайты и CDN). В «Все правилах» — только пока приложение в сети. Уже в списке — «✓» и переход
  к группе на вкладке.
- Меню соединения:
  - «Только IP x.x.x.x» → «Мимо Шлюпки»: один адрес.
  - «Сайт X и поддомены» → «Мимо Шлюпки»: сразу адреса текущих соединений с этим сайтом, дальше
    дозапоминание раз в 10 с (как адреса игр), забывание через 30 дней. Подменных адресов в ядре нет,
    имя берётся из соединения (sniff), поэтому это работает. Адрес, на который ходят и другие сайты,
    не берём и пишем «общий с другими сайтами» (CDN: на нём бывают заблокированные сайты).
  - «Сайт — в группу»: без изменений.
- «Ошибки»: значок «мимо Шлюпки» рядом с IP в каждой строке; рядом с «Скопировать IP (n)» кнопка
  «IP (n) мимо Шлюпки», n — уникальные публичные IPv4 этого сайта или программы.

## Этап 3. Вкладка «Мимо Шлюпки»

- Убрать кнопку «Никогда мимо…» (запрет остаётся в меню адреса).
- Пункты меню адреса: «Убрать» (игра может запомнить снова) и «Убрать и больше не добавлять».
- Группировка по приложениям и сайтам, как в «Сейчас в сети»; «Добавлено вами»; сети Blizzard и Steam.
- Две колонки: «Мимо Шлюпки» и «Только через Шлюпку» (бывшее «Никогда мимо»); в узком окне друг под другом.
- В «Только через Шлюпку» вместо «Разрешить» два пункта: «Вернуть в «Мимо Шлюпки»» и «Удалить из списка».

## Этап 4. Меню пути

- «Авто», «Мимо VPN», «Через VPN ▸». В подменю: «Любой — выберет Шлюпка» и серверы.

## Этап 5. Сети Steam

- Список сетей Valve (AS32590) по образцу Blizzard, переключатель «Сети Steam». Действует, когда
  Steam или его игра в «Мимо VPN». Помогает только играм Valve (CS2, Dota 2); адресов игровых
  серверов Steam в журналах нет, только магазин и CDN — их не брать.

## Этап 6. «Сейчас в сети»

- Метка у приложения «часть трафика мимо Шлюпки — здесь не видна»; по нажатию — его группа на вкладке.

## Этап 7. Перенос привязок при смене имён серверов

- Правила и выбранный сервер привязаны к имени. При обновлении подписки сопоставлять старый и новый
  сервер по адресу и порту и переносить привязку.

## Ручные тесты

Проверка пути: `Test-NetConnection <IP> -Port 443` или `Find-NetRoute -RemoteIPAddress <IP>`:
`tun0` / 172.19.0.1 — через Шлюпку, `Ethernet` / 192.168.1.57 — мимо.

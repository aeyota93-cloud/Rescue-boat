# Группы в «Раздельном туннеле» (v1, 2026-10-13)

Пользователь 13.10: «группировать ресурсы или процессы своими группами, которые можно назвать
и управлять как массово (для всей группы), так и отдельно». Встроенная строка «Игры и
лаунчеры» заменена группами.

## Что такое группа

- Имя и состав: программы, сайты, IP (`split-tunnel.json` → `groups: [{name, apps, domains, ips}]`).
- Запись — не больше чем в одной группе. Пустых групп нет: ушла последняя запись — группы нет.
- Группа — только для удобства в приложении. Путь у каждой записи свой (списки «через VPN»,
  «мимо VPN», серверы — как раньше), ядро групп не видит и ничего про них не знает.
- «Убрать из списков» у записи не выводит её из группы: в группе она остаётся с «Авто».

## Экран

> С 14.10 экран другой — карточки групп и вкладка «Сейчас в сети»: docs/redesign/tunnel-v3.md.
> Ниже — как было в 0.2.0.

- Записи без группы — как раньше, сверху. Ниже — строки групп с пунктирной рамкой:
  «<имя> · N», подпись «группа · <где> · раскрыть». <где>: «через запасной 2», если все за
  одним сервером; «разные серверы» — все через VPN, но по-разному; «разные пути» — кто как.
- Переключатель «Авто / Мимо / VPN» у группы ставит всем записям; при разных путях — без выбора.
- «⋯» у группы: «Через VPN ▸ Авто / Основной / Запасной 1 / …», «Мимо VPN», «Переименовать…»,
  «Удалить группу (записи останутся)». Переименование в занятое имя сливает группы.
- «⋯» у записи: «В группу ▸ <группы> / Новая группа…», «Убрать из группы «…»».
- Раскрытая группа показывает свои записи с отступом, у каждой — свой переключатель и меню.
- При поиске групп нет — всё одним списком. На закладках «Мимо» / «Через VPN» группа
  показывает только подходящие записи и управляет только ими.

## Стандартные группы

`suggestedGroups` в `lib/features/split_tunnel/model/split_tunnel.dart`: «Игры», «Marvel Rivals»,
«Античиты», «Лаунчеры и магазины», «League of Legends и Riot», «Общение», «Служебное для игр».
Записи попадают в них, только если они есть в списках:

- первый запуск (`SplitTunnel.defaults`) — игры и лаунчеры по умолчанию сразу по группам;
- старый файл без поля `groups` — записи раскладываются при чтении (поле есть, пусть пустое, —
  не трогаем: пользователь мог удалить группы сам).

# Раздельный туннель v3: «Сейчас в сети» и «Группы» (2026-10-14)

Пользователь 13.10, после 0.2.0: «стало очень непонятно». Разобрали экран, сделали три макета
(полки по серверам, папки-карточки, спокойный список). Выбран вариант «папки». К нему добавили:
перенос между группами, «В группу» для записей без группы, выбор группы при добавлении. По просьбе
пользователя добавили вкладку с соединениями прямо сейчас. Таблица «Все / Мимо / Через VPN» убрана.

## Вкладка «Сейчас в сети» (открывается первой)

- Сводка: сколько открытых соединений и полоска «куда ушли»: Основной / Запасные / Мимо VPN.
- Фильтры: Все / Через VPN / Мимо / Без правила. «Без правила» — сработали общие правила («Авто»).
- Вид: «По программам» или «По группам» (разделы с «открыть группу»).
- Строка программы: название (справочник `app_names.dart`, потом описание файла, потом имя), кнопка
  группы, соединения и трафик, цветные метки реального выхода, плашка пути программы.
- Раскрыть программу: каждое соединение — адрес, **почему так**, трафик, метка выхода и «⋯».
  «⋯» направляет сайт целиком, только IP или кладёт сайт в группу.
- Почему так (`ruleFor` в `model/live_view.dart`): записи проверяются в том же порядке, что и
  в ядре (`split_tunnel.go`). Сначала записи за серверами (их правила стоят выше, если серверов два и
  больше), потом «через VPN», потом «мимо». Если ни одна не подошла — «Авто: общие правила».
  Реальный выход берётся из цепочки clash API, а не вычисляется.
- Закрывшиеся соединения видны ещё минуту, бледными с пометкой «закрыто», и не идут в сводку.
- VPN выключен: подсказка и кнопка «Открыть группы».

## Вкладка «Группы»

- Карточка группы: превью записей, «Авто / Мимо / VPN» всем сразу. При «VPN» и нескольких
  серверах ниже строка «Сервер: Любой ▾ / Запасной 2 ▾». Разные пути — оранжевая строка
  «Разные пути: …» и «Выровнять». Внизу соединения, «не удалось N», «Открыть». «⋯»:
  «Переименовать…», «Удалить группу (записи останутся)».
- «Без группы» — последняя карточка, если такие записи есть.
- Открытая группа — панель справа (на узком окне вместо карточек, «← Все группы»). У записи
  отметка, путь, кнопка «Перенести» (группы, новая, убрать, открыть). Записи, идущие не как у
  большинства, подписаны «не как у группы». Отмеченные — полоса «Выбрано N · В группу · путь».
  Записи можно перетащить на карточку группы.
- Поиск — без карточек, найденные записи одним списком.

## Окна

- «+ Добавить» и «Из запущенных» — одно окно с закладками «Вписать / Из запущенных».
  - Вписать можно несколько записей: по строке или через запятую. Есть «Файл .exe…».
  - Группа: «Без группы», группы, «+ Новая…».
  - Путь: «Как у группы» (если пути в группе разные — «как у большинства»), Авто, Мимо, VPN,
    серверы.
  - «Без группы» вместе с «Авто» ничего не меняет — кнопка неактивна, рядом объяснение.
- «Новая группа»: название и отметки по любым записям (из других групп они переносятся).
  Пустую группу создать нельзя.
